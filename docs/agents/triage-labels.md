# Triage Labels

Las skills hablan en términos de cinco roles canónicos de triage. Este fichero mapea esos roles a
las cadenas de label reales que usa el issue tracker de este repositorio.

| Label en mattpocock/skills | Label en nuestro tracker | Significado                                              |
| -------------------------- | ------------------------ | -------------------------------------------------------- |
| `needs-triage`             | `needs-triage`           | El mantenedor tiene que evaluar esta incidencia          |
| `needs-info`               | `needs-info`             | Esperando más información de quien la reportó            |
| `ready-for-agent`          | `ready-for-agent`        | Totalmente especificada, lista para un agente autónomo   |
| `ready-for-human`          | `ready-for-human`        | Requiere implementación humana                           |
| `wontfix`                  | `wontfix`                | No se va a abordar                                       |

Cuando una skill mencione un rol (p. ej. "aplica la label de triage lista para AFK"), usa la cadena
de label correspondiente de esta tabla.

Edita la columna "Label en nuestro tracker" para que coincida con el vocabulario que uses de verdad.
